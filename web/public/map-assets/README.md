# Self-hosted map assets

Glyphs and grayscale sprites copied from [Protomaps basemaps-assets](https://github.com/protomaps/basemaps-assets/tree/028c18f713baecad011301ff7a69acc39bcc2ae7) at commit `028c18f713baecad011301ff7a69acc39bcc2ae7`.

The three Noto Sans faces include Basic Latin/Latin-1, Latin Extended-A/B, and general punctuation blocks for English/Spanish labels in this San Diego map. Fonts use the included SIL OFL; sprites derive from Tangram icons under the included MIT license.

MapLibre worker/shared modules and their BSD license are copied from the exact installed package during `npm run assets`; generated files are ignored by Git.
