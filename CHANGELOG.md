# Changelog

## 1.0.0 — October 25, 2026

First versioned release of Outlook SD, available at [outlook-sd.vercel.app](https://outlook-sd.vercel.app/).

- Five environmental-hazard outlooks, official warning links, source freshness and model track records.
- An interactive San Diego map, saved neighborhoods, place comparisons and a three-day planning brief.
- Community summaries with 27 observation choices, reporting gaps and protected withdrawal of new reports within 24 hours.
- Historical scenarios, responsive controls, accessible chart data and loading/error recovery.
- Verified hourly forecast publishing, static deployment packaging and public snapshot checks.

This release also shortens the README, separates model evaluation from setup instructions, corrects outdated status statements and aligns version metadata.

See [verification](docs/STATUS.md), [model limitations](docs/MODELS.md), [community safeguards](docs/COMMUNITY_SAFEGUARDS.md) and [credits and development assistance](CREDITS.md). Forecasts remain estimates; community reports remain unverified.

The `v1.0.0` tag records the source release. The separate `state` release holds runtime forecast data and continues to update.
